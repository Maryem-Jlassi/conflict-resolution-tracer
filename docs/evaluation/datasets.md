# Datasets

This page describes the datasets used for CRT evaluation, including dataset cards, synthetic diagnostics, external benchmarks, split manifests, and hash verification.

## Current Dataset Status

> **No approved real conflict corpus is currently installed.**

The project does not yet have an independently adjudicated real-world conflict dataset. All current empirical evaluation is blocked on dataset acquisition and annotation.

## Synthetic / Controlled Diagnostic Datasets

Engineering validation uses deterministic synthetic cases generated by `research_evaluation/engineering_evaluation.py::generate_cases()`:

- **Controlled diagnostic set**: 128 cases generated with a 7-bit factorial design.
  - Bits control: `evidence_right`, `trust_right`, `recent_right`, `provenance_right`, `domain_match`, `compatible`, `duplicate_source`.
  - Each case has deterministic `existing_claim` and `incoming_claim` with known oracle labels.
  - Used for conformance, sensitivity, and security testing.
- **Corrected Benchmark D scenarios**: Diagnostic conflict scenarios from `docs/research_evaluation/dataset_card_v1_conflict_benchmark.md`.

These synthetic datasets are useful for engineering validation (does the code do what we expect?) but do not establish empirical correctness on real human conflict.

## Dataset Cards

Dataset cards describe the schema, intended use, and limitations of each evaluation dataset:

- `docs/research_evaluation/dataset_card.md` — Original dataset card.
- `docs/research_evaluation/dataset_card_v1_conflict_benchmark.md` — Updated card for the conflict benchmark.
- `docs/research_evaluation/policy_separation_dataset_card_v1.md` — Dataset card for policy-separation experiments.

Each card specifies:
- Dataset name and version.
- Schema version (1.0 for `ConflictCase`, 2.0 for `ConflictEpisode`).
- Independent unit definition.
- Split policy.
- Ground-truth status (independently adjudicated or not).
- Research classification (`diagnostic`, `engineering`, `empirical`).

## Split Manifests

Split assignments are managed by `research_evaluation/splits.py` and `research_evaluation/dataset.py::split_manifest()`:

- Splits group episodes by entity, source family, domain, time period, and conflict family.
- No entity or source family may leak across splits.
- Temporal leakage is also forbidden.
- Once frozen, the manifest is immutable and its SHA-256 hash is recorded.

## Hash Verification

All artifacts are hash-verified:

- `research_evaluation/dataset.py::canonical_hash()` computes deterministic SHA-256 hashes of case payloads.
- `research_evaluation/frozen_artifacts.py::sha256_file()` computes file-level hashes.
- `research_evaluation/frozen_artifacts.py::validate_final_authorization()` checks that the split-manifest hash in the authorization record matches the current file hash.
- `research_evaluation/dataset.py::assert_frozen_test_writable()` blocks writes to test artifacts unless the current hash matches the expected manifest hash or an explicit unlock is provided.

## Dataset Schema

### `ConflictCase` (schema 1.0)

```python
class ConflictCase(BaseModel):
    schema_version: Literal["1.0"]
    case_id: str
    domain: str
    entity_id: str
    source_family: str
    existing_claim: Claim
    incoming_claim: Claim
    evidence_artifacts: list[dict[str, Any]]
    event_timestamps: list[datetime]
    validity_interval: Optional[dict[str, Optional[datetime]]]
    adjudicated_outcome: Optional[FinalLabel]
    ambiguity_reason: Optional[str]
    annotator_records: list[AnnotatorRecord]
    adjudication_status: Literal["unannotated", "in_progress", "agreement", "adjudicated", "escalated"]
    split: Optional[Literal["pilot", "train", "validation", "test"]]
    artifact_hashes: dict[str, str]
```

### `ConflictEpisode` (schema 2.0)

```python
class ConflictEpisode(BaseModel):
    schema_version: Literal["2.0"]
    episode_id: str
    domain: str
    entity_ids: list[str]
    conflict_family: str
    evaluation_time: datetime
    claims: list[EpisodeClaim]          # min 2
    truth_timeline: list[TruthInterval]
    expected_abstention: bool
    annotations: list[AnnotatorRecord]
    adjudication_status: ...
    adjudicator_id: Optional[str]
    split: Optional[Literal["pilot", "train", "validation", "test", ...]]
    artifact_hashes: dict[str, str]
```
